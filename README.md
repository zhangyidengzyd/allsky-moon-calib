# 全天空气辉成像仪 月亮法定标 + 气辉投影（代码包）

配套论文《无星条件下的全天空气辉成像仪几何定标与气辉投影方法》的**自包含**代码包。

针对的问题是：180 s 长积分的存档气辉数据里恒星无法可靠提取，因此需要一套**不依赖可辨识星点**的几何定标方法——用月亮的位置与方位作为参照，显式解耦"圆心／方位定向角／径向标度"的简并，并从存档数据里恢复定量的地理信息。

---

## 1 一分钟验证这个包是好的

```matlab
>> cd <本包根目录>
>> run_demo('check')
```

它会跑两件事，**都不需要原始图像**：

| 自检 | 做什么 | 通过标准 |
|---|---|---|
| `verify_paths` | ① 可执行代码里的盘符 ② 依赖闭包 ③ 输入侧数据齐备 | 三项全过 |
| `verify_paper_numbers` | 把论文表 1、式 (5)、以及"合 10 夜 rot = 4.283° ± 0.204°"**逐条**回溯到 `data/calib/*.mat` | 全部通过 |

之所以能做到"不需要原始数据"，是因为 `data/calib/` 里随包给了三个时期的**采用解**与**逐帧月核量测缓存**（合计约 90 KB）。论文 §3 的全部定标数值、以及 §3.2 的跨期一致性结论，都能从这里逐位复算。

## 5 运行前必须确认的事项

★ 这一节是**实测出来的系统误差源**，不是泛泛的注意事项。按影响从大到小排。

### 5.1 站点经度（最大误差源）

`q_cfg.m` 里 `cfg.site = [109.133, 19.526, 0.103]` 是儋州（海南富克站 FKT）的官方坐标。**方位定向角 rot 的精度由它决定**——经度差一个量级就会把 rot 带偏。若换站：只改 `cfg.site`，并**重跑定标**（换站只改 rot，见 `moon_calib.m` 里 `rot = φ − A` 的口径）。

注意 PNG 头里的坐标**不可信**：二期头坐标写的是 `(109.830, 19.310)`，与官方差 0.70°E ≈ 250 km 高度上 73 km；一期头坐标又是另一个值。本链一律用 `cfg.site`。

### 5.2 时间戳 = 曝光中点（不要 +90 s）

这一条是**判出来的**，不是假设的：用 369 帧月核、4 个合格夜、10 s 步长扫时间偏移，总残差极小在 **−27 s**、径向通道 **−18.5 s**。若时间戳是曝光**起点**，极小应落在 **+90 s**；是终点则落在 **−90 s**——两者都被排除。

残留 30 s 折算 rot 不确定度 **≤ 0.08°**（灵敏度 0.160 °/min），小于跨夜散布 ±0.41°。

> 若你的数据时间戳是曝光起点，必须先给整批帧加 90 s 再进入本链，否则 rot 会引入约 0.2° 的系统偏置。

### 5.3 暗场必须给

`cfg.darkFile` 置空会警告，且**耗竭率会被 3441 DN 的基座稀释一半以上**——结果只能看形态、不能看振幅。随包已给暗场。

### 5.4 天顶角限幅 `zMax = 70°`（不要往上抬）

两个依据：① 径向标定只在 **z < 76°** 有实测锚点（月亮高度 14°–50°）；② 分辨率随 z 发散。限制来自"锚点 + 分辨率"，**不来自视场**，所以抬到 75°–80° 只会把外推误差混进结果。

### 5.5 圆心可辨识性——2013 批必须钉住圆心

天顶像点能否被数据定出，取决于月亮扫过的**方位范围**。2013-10 批的月亮方位跨度不足，默认流程给出的圆心是**伪极小**；本包的 2013 采用解是把圆心约束到 2014 的独立解（`CenterFix`）后得到的。因此：

* 2013 的正确读法是 **parameter-transfer consistency test**（参数迁移一致性检验），**不是** independent validation。
* 要跨批比较 rot，**必须同口径**（同样给定 `CenterFix`），否则会拿两个不同的解相比。

### 5.6 别动 `data/calib/` 里那几个解再重跑投影

`data/calib/*.mat` 是论文数值的来源。`run_demo('project', …)` 会读 `cfg.calFile`（= `phase2_pipe.mat`）。若你先跑了 `run_demo('calib')`，它就被覆盖了。

## 6 关键参数（都在 `q_cfg.m`）

| 参数 | 默认 | 含义 |
|---|---|---|

## 8 已知限制 / 有意未随包的内容

1. **原始帧未随包**（约 240 GB）。因此 `run_demo('project' / 'bubble' / 'calib')` 需要你先把数据放进 `data/raw/`；只有 `run_demo('check')` 是开箱即用的。
2. **`thesis_fig_probe.m` 未随包**。它用于量取第三方学位论文（马欣 2021）插图里的坐标系，依赖一份**受版权保护、不能随包分发**的 docx。其结论已写入论文 §3.2。需要复算请自备该文档。
3. **本包只覆盖方法链（纯 MATLAB）**。论文排版、插图成图的构建脚本（md → DOCX、matplotlib 出图）属于出版工序，不在方法范围内。
4. `q3_bubble` / `q5_moon` 的泡团量测依赖 `bubble_work` 里 `drift_centroid` 一类的派生脚本；若只关心定标与投影，不用管这条线。
5. 泡团漂移速度的**写死口径**：本包里 `out/logs/` 下的漂移量测用的是"经度轴途径"（不依赖 `r(z)`）。若要换成"像素位移 × dD/dr"途径，注意两条途径的**速度尺度不同**——气辉层纬向 1° 在 250 km 上是 **108.91 km**，不是地面的 104.80 km；混用会差 3.9%。
6. 投影高度取 250 km 是**假定**。由 IRI-2020 给出的同期 `hmF2 ≈ 303 km` 可知发射率峰位于其下，故 250 km 合理；但 h 的 200→300 km 变化会给漂移速度带来 **±19%** 的量级，这是速度误差的主项。
