# 数据放置

```text
data/
├─ raw/          原始帧（**未随包提供**，按日期分子目录）
│   └─ 20250920/ODAZH_DCAI01_AROA_L0_STP_20250920114250_V01.00.PNG
├─ dark/         暗场 PNG（随包，约 1 MB）
└─ calib/        定标结果与逐帧月核量测缓存（随包，约 90 KB）
```

## 1 raw/ —— 原始帧

* 一夜一个日期目录，`*.PNG` **直接**放在日期目录里（不要再套一层）。
* 文件名通配：`ODAZH_DCAI01_AROA_L0_STP_*.PNG`（改 `q_cfg.m` 的 `cfg.pattern`）。
* 幅面 1024×1024；二期 16 bit，一期 2013/2014 为 8 bit；采样间隔 180 s。
* 文件名里的时间戳是 **UT**，对应**曝光中点**（判据见 README §5.2）。
* 一期与二期放同一个 `data/raw/` 即可（日期不冲突）。

**为什么未随包**：全部原始帧约 **240 GB**。二期（2025–2026）帧请向作者索取；
一期对应时段可用公开数据集：国家空间科学数据中心「海南富克站全天空气辉成像仪原始数据」，
覆盖 2010-04 – 2021-12，DOI [10.12176/01.05.010](https://doi.org/10.12176/01.05.010)。

> `run_demo('check')` **不需要** `raw/` 就能跑——它只读 `calib/`。

## 2 dark/ —— 暗场

随包文件：`ODAZH_DCAI01_DFOA_AUX_STP_20260516115948_V01.00.PNG`。

★ **不要省**。置空暗场会让耗竭率被约 3441 DN 的偏置基座稀释一半以上，
结果只能看形态、不能看振幅。路径在 `mc_paths.m` 的 `P.dark`。

## 3 calib/ —— 随包的参考解

| 文件 | 内容 | 变量 |
|---|---|---|
| `phase2_native.mat` | 二期 2026-03 采用解（349 帧 / 5 夜） | `calMat`，**0-based** |
| `phase2_pipe.mat` | 同上，管线格式 | `cal`，1-based，`rz_poly` 为"度"制 8 元 |
| `phase2_meas.mat` | 二期逐帧月核量测缓存（448 帧） | `night / ts / cx / cy / cxs / cys / nsat / peak` |
| `phase1_2014_native.mat` / `_pipe.mat` / `_meas.mat` | 一期 2014-09（316 帧 / 6 夜） | 同上 |
| `phase1_2013_native.mat` / `_pipe.mat` / `_meas.mat` | 一期 2013-10（194 帧 / 5 夜） | 同上 |

★ **0-based 与 1-based**：`calMat` 的 `x0/y0` 是 **0-based**（原始 IDL/Python 口径），
`cal.zenith` 是 **1-based**（MATLAB 口径）；`moon_calib_to_pipeline.m` 负责 +1。
`rot` 的符号**原号照抄**，不取反。

★ **重跑定标会覆盖这里**（设计使然：定标输出就是投影输入）。要保留请先整包拷贝。

## 4 数据可以用别处

`data/` 只是默认位置。路径全部由 `src/mc_paths.m` 派生，改那一个文件就能把
数据/产物挪到任何地方（例如指向外部大盘），**不需要动任何其它文件**。
