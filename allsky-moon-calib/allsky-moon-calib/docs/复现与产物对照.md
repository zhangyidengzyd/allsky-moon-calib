## 2 式 (5) 与 §3.2 的跨期结论

| 论文处 | 值 | 来源 |
|---|---|---|
| 式 (5) 2014-09 | +0.14 °/px | `phase1_2014_native.mat` → `calMat.rot_per_y0` = +0.143494 |
| 式 (5) 2013-10 | −0.17 °/px | `phase1_2013_native.mat` → `calMat.rot_per_y0` = −0.174032 |
| §3.2 "2013 与 2014 相差 0.15°" | 0.15° | `abs(rot_2013 − rot_2014)` = 0.147057 |
| §3.2 "剔 20131021 后合 10 夜 rot = 4.283° ± 0.204°" | 4.283 / 0.204 | 两期 `calMat.rot_per_night` 的**圆均值与圆散布**，剔掉 `20131021`；共 498 帧 |

产生者：`calib_2014.m` 的 `rotPerY0` 段（约 922–928 行）写 `rot_per_y0`；
`rot_per_night` 在 `adopt_solution` 的"逐夜 rot（在采用解下重算）"段。

复算命令（除 `run_demo('check')` 外也可以手工走）：

```matlab
>> MP = mc_paths(); S14 = load(MP.calP14Native); S13 = load(MP.calP13Native);
>> pn = [S14.calMat.rot_per_night, S13.calMat.rot_per_night];
>> keep = ~strcmp({pn.night}, '20131021');
>> r = [pn(keep).rot];
>> m = mod(atan2(mean(sind(r)), mean(cosd(r))) * 180/pi, 360)
>> R = abs(mean(exp(1i * deg2rad(r)))); s = sqrt(-2*log(R)) * 180/pi
```

### 6.1 表 3 的速度值（101 m/s = 365 km/h）

本文那一行的量测链：地理投影图 → 逐帧暗核质心 → 经度变化率 × **108.91 km/°**（气辉层纬向尺度）。

⚠ **速度换算的三个"1 度"** 见 `docs/公式与代码对照.md` 式 (9) 一节。用地面尺度 104.80 km/° 会低估 3.9%（365 → 351 km/h）。

### 6.2 §4.3 的高度不确定度

h = 250 km 是**假定**，由 IRI-2020 的同期 `hmF2 ≈ 303 km` 支持（发射率峰位于其下）。
h 由 250 → 300 km 使漂移速度 **+18.3%**（z = 35°），200 → 300 km 全程约 **±19%**，是速度误差的主项。
实现见 `airglow_geo_pipeline.m` `ground_dist_from_r`。

## 7 §3.1 的"可辨识性"论证（为什么不能用星点法）

| 证据 | 复算入口 |
|---|---|
| 转动一致性（15.0411 °/h 跟随自转 vs 不转动，星表命中率） | `moon_calib.m` 的普查/检测阶段；论文 §3.1 的两项判决之一 |
| 跨季像素重合（相隔 293 天的亮点掩模重合率） | 同上 |
| "星法 rot 不可辨识" 的结论 | 由以上两项 + `zenith_from_rim.m`（几何法只能给光轴像点与视场半径，**给不出 rot**，这是对称性所致而非精度问题） |

`zenith_from_rim.m` 的能力边界写得很明确：等天顶角的像点落在以光轴像点为圆心的圆上；把整组同心圆绕圆心旋转任意角度目标函数不变 ⇒ **rot 不可辨识**。
