## 式 (3) 方位定向角

> `rot = φ − A`（A = 同一时刻星历给出的月亮方位角）

| 文件 | 函数（行号） | 说明 |
|---|---|---|
| `src/moon_calib.m` | `mc_meas_to_geo` (1106) | 给每条测量补上星历量并算 `rot_dir = φ − A` 与 `rot_mir = −φ − A`（直接／镜像两种手性） |
| `src/moon_calib.m` | `mc_circstats` (598) | 圆均值／圆散布 |
| `src/moon_calib.m` | `mc_lm` (1229) | rot 作为**自由参数**参与拟合，不直接代入式 (3)（式 (3) 要求月亮方位角无误差） |

★ `rot = φ − A` 是**纯方向量**，与径向是否畸变无关：径向畸变只把 r 换成某个单调函数，φ 分毫不动。这正是"方位信息与径向模型解耦"的由来，也是 §2.2 破简并的立足点。

## 式 (4) 天顶像点的可辨识性

> `δφ = ( sin φ · δx₀ + cos φ · δy₀ ) / r`

解析推导。代码里对应的**实测量**有两处：

| 文件 | 函数（行号） | 说明 |
|---|---|---|
| `src/moon_calib.m` | `mc_gate_by_night` (1134) | 逐夜统计表里带 `az_span` 字段 —— 月亮在该夜扫过的方位跨度，就是 δφ 能否被平均掉的关键 |
| `src/calib_2014.m` | `rotPerY0`（`adopt_solution` 内，约 922–928 行） | 直接**实测**简并线的斜率：把圆心沿 y 挪 10 px 再解一次 rot |

判据（论文与代码一致）：方位跨度不足 ⇒ 圆心不可辨识。因此**跨批次比较 rot 时必须把圆心钉在已有可信值上**，使各批之间只差数据一个变量。

## 式 (6) 像面方位角 ⚠

> 期刊印刷版：`φ = atan2( x₀ − x, −(y₀ − y) )`

### ⚠ 与代码差 180°，判定为排版符号笔误

| 位置 | 写法 |
|---|---|
| **代码**（`src/moon_calib.m` `mc_meas_to_geo` 内，约 1121 行） | `phi = mod(rad2deg(atan2(dx, -dy)), 360.0)`，其中 `dx = cx − x0`，`dy = cy − y0` |
| **代码**（`src/calib_2014.m` `search_center` 的注释，约 1012 行） | 明确写"像面方位 `phi = atan2(cx−x0, -(cy−y0))`" |
| **期刊式 (6)** | `atan2( x₀ − x, −(y₀ − y) )` |

两者相差**恒定的 180°**（两个自变量同时取反）。

**为什么结论不受影响：**

* 式 (7) 的共识计数 `S = #{ i : |φ_i − A_i − m| ≤ 2° }` 里，`m` 是 `φ − A` 的中位数，会把任何**常数**偏移吸收掉 ⇒ **S 对 φ 的整体 180° 偏移不变**。
* 式 (8) 的 χ² 直接用式 (2) 算模型坐标，不经过式 (6) ⇒ 不受影响。
* 受影响的只有"按式 (3) 直接算 rot"这一步：照印刷版算会得到 `rot + 180°`，与表 1 的 +0.39 / +4.35 / +4.20 对不上。

**建议**：把式 (6) 的第一个自变量改成 `x − x₀`（即 `φ = atan2( x − x₀, −(y − y₀) )`），与式 (2) 及代码一致。
自洽校验：`atan2(dx, −dy)` 在正北（dy<0, dx=0）给 0°、在正东（dx>0, dy=0）给 +90°，即"自北起、经东为正"，与式 (2) 完全一致。

## 式 (7) 全局紧截尾共识定圆心

> `S(x₀, y₀) = #{ i : | φ_i(x₀,y₀) − A_i − m | ≤ 2° }`

| 文件 | 函数（行号） | 说明 |
|---|---|---|
| `src/calib_2014.m` | `search_center` (1006) | 三级网格：4 px 粗搜 → 1 px → 0.5 px 亚像素 |
| `src/calib_2014.m` | `center_cost` (1047) | 代价 = 内点圆方差（deg²）＋ 内点比例不足的罚项 `1e4·(MinInlierFrac − frac)²` |
| `src/calib_2014.m` | `tight_inliers` (1060) | ±`InlierHalfWidth` 的内点集 |
| `src/calib_2014.m` | 参数默认值 149–151 行 | `AltHiCenter = 70`（定心窗口）、`InlierHalfWidth = 2.0`、`MinInlierFrac = 0.80` |

★ 判据里的 `±2°`、`MinInlierFrac = 0.80`、`AltHiCenter = 70°` 三个数都集中在 `calib_2014.m` 的 `inputParser` 段，改判据只改那里。

★ 为什么不用"逐夜 rot 的汇总量"（旧做法）：坏夜（20140930 / 20141007）的 rot 分布又宽又偏（散布 32–35°），此时圆均值、圆中位、3σ 截尾均值会给出相差 10° 的三个答案，任何一个都能被"凑"到与其他夜一致 ⇒ 代价被坏夜的汇总量支配，极小跑到 (535,543) 这种伪解上。全局紧截尾不用汇总量，只有真月亮帧能过 ±2° 共识。

## 式 (8) 固定圆心后的最小二乘

> `χ²(rot, f, a) = Σ_i [ (x_i^obs − x_i^mod)² + (y_i^obs − y_i^mod)² ]`

| 文件 | 函数（行号） | 说明 |
|---|---|---|
| `src/moon_calib.m` | `mc_res_geo` (1221) | 残差向量（用 `mc_r_of_z` + 式 (2)） |
| `src/moon_calib.m` | `mc_lm` (1229) | **自实现 Levenberg–Marquardt，不依赖 Optimization Toolbox** |
| `src/moon_calib.m` | `mc_numjac` (1294) | 中心差分数值 Jacobian |
| `src/moon_calib.m` | `mc_grid_fit` (1334) | 5 模型 × 2 手性的网格搜索，取二维残差最小者 |
| `src/moon_calib.m` | `mc_solve` (1485) | 阶段 3 主控：判据筛选 → 坏夜剔除 → 模型/手性 → 不确定度 → 一致性检验 → 断言 |
| `src/calib_2014.m` | `fit_model` (1101) | 一期版本 |

⚠ **`mc_lm` 的奇异点**：`equidistant / equisolid / orthographic / stereographic` 四种模型**不使用**参数 `a`，Jacobian 第 5 列恒为 0 ⇒ 法方程奇异。`mc_lm` 里对此有专门处理，不要删。

## 式 (9) 天顶角 → 地面距离

> `ψ(z) = z − arcsin[ R·sin z / (R + h) ]`，　`D = R · ψ(z)`

| 文件 | 函数（行号） | 说明 |
|---|---|---|
| `src/airglow_geo_pipeline.m` | `ground_dist_from_r` (388) | ★ **实现方式与印刷式不同但等价**：代码解隐式方程 `atan2d(R_air·sin g, R_air·cos g − R_obs) − z_m = 0`（`fzero`），因为闭式在 z→90° 时数值不稳；两者在 z = 35°、h = 250 km 下都给 ψ = 1.50°、D = 166.7 km |
| `src/airglow_geo_pipeline.m` | `initial_bearing_deg` (427) | 由站点沿方位 az 做球面推算 |
| `src/bubble_night.m` | `gamma_of_z` (228) | 泡团处理用的同一换算 |
| `src/moon_canvas_pos.m` | `gamma_of_z` (51) | 月面在 250 km 画布上的位置 |

### ★ 速度换算的三个"1 度"（极易混用）

| 口径 | 值 | 用在哪 |
|---|---|---|
| 地面纬向 `111.195·cos(lat₀)` | **104.80 km/°** | 画布正方形自检 |
| **气辉层纬向 `(R+250)·cos(lat₀)·π/180`** | **108.91 km/°** | ← **测漂移速度该用这个** |
| 气辉层大圆 `(R+250)·π/180` | 115.55 km/° | 南北向距离 |

混用会差 3.9%（351 → 365 km/h）。**高度 h 的影响**：h 由 250 → 300 km 使漂移速度 +18.3%（z = 35°），200 → 300 km 全程约 ±19%，这是漂移速度误差的主项。
