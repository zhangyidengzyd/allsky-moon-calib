# raw/ —— 原始帧（**未随包提供**）

把原始帧按「一夜一个日期目录」放进来即可：

```text
data/raw/
└─ 20250920/
    ├─ ODAZH_DCAI01_AROA_L0_STP_20250920114250_V01.00.PNG
    └─ ...
```

* 文件名通配：`ODAZH_DCAI01_AROA_L0_STP_*.PNG`（改 `src/q_cfg.m` 的 `cfg.pattern`）。
* 幅面 1024×1024；二期 16 bit，一期 2013/2014 为 8 bit；采样间隔 180 s。
* 文件名时间戳为 **UT**，对应**曝光中点**。
* 一期与二期可放同一个 `raw/` 下（日期不冲突）。

## 为什么未随包

全部原始帧约 **240 GB**。

* 二期（2025–2026）帧请向作者索取。
* 一期对应时段可用公开数据集：国家空间科学数据中心
  「海南富克站全天空气辉成像仪原始数据」，覆盖 2010-04 – 2021-12，
  DOI [10.12176/01.05.010](https://doi.org/10.12176/01.05.010)。

> `run_demo('check')` 与 `run_demo('calib')` **不需要**本目录：
> `check` 只读 `../calib/`，`calib` 用 `mc_pipeline_e2e_test` 现场合成帧。

详见 [`../README.md`](../README.md) 与包根 `README.md` §「数据放置」。
